# OLED Experiments

A collection of my projects using OLED displays and microcontrollers, from basic display experiments to interactive games.

## Projects

- **HelloWorldAnimation** – Displaying animated text on an OLED.
- **LeftRightButton** – Experimenting with button inputs and navigation.
- **oled_display** – Basic OLED display experiments.
- **OLEDAddressFinder** – Finding I²C addresses of connected devices.
- **SpaceShipDodge** – A simple spaceship dodging game on an OLED.
- **Tetris** – A Tetris game running on an OLED display.

## Components

- Microcontroller (Arduino or ESP32, depending on the project)
- OLED display
- Push buttons
- Jumper wires
- Breadboard (if required)
